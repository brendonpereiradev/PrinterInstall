1. VISAO GERAL E PRE-REQUISITOS
================================================================================

O PrinterInstall executa a instalacao e a configuracao de impressoras de rede
em estacoes de trabalho Windows, seja na propria maquina ou em computadores
remotos. O programa realiza as seguintes etapas:
- Instala os drivers no sistema operacional a partir dos pacotes homologados.
- Cria as portas TCP/IP de comunicacao direta.
- Cria as filas de impressao com a nomenclatura definida pelo operador.
- Aplica as dimensoes corretas em impressoras termicas de etiqueta (Gainscha).
- Desfaz alteracoes parciais caso ocorra falha ou cancelamento (Rollback).

Pre-requisitos para operacao:
1. Credenciais com privilegios administrativos no dominio ou na maquina remota.
2. Identificacao dos computadores de destino:
   - Nome de rede nos padroes corporativos (exemplo: NOTE-001234 ou 113-DESK004567).
   - Ou endereco IP fixo da estacao na rede (exemplo: 192.168.10.120).
3. Endereco IP fixo ou reservado da impressora (exemplo: 192.168.10.50).


================================================================================
2. ACESSO AO SISTEMA (LOGIN) E CONFIGURACAO DE DOMINIO
================================================================================

Na abertura do aplicativo, informe suas credenciais de rede na tela de autenticacao:

  +-------------------------------------------------------------+
  |                     PRINTERINSTALL - LOGIN            [⚙]  |
  +-------------------------------------------------------------+
  |  Usuario: [ suporte.silva                                ]  |
  |  Senha:   [ ******************                           ]  |
  |  [X] Lembrar-me                                             |
  |                                                             |
  |                      [  ENTRAR  ]                           |
  +-------------------------------------------------------------+

Formatos aceitos no campo Usuario:
- Formato UPN: usuario@dominio (exemplo: suporte.ti@empresa.local).
- Formato NetBIOS: DOMINIO\usuario (exemplo: EMPRESA\suporte.ti).
- Apenas o nome de usuario: digitando "suporte.ti", o sistema aplica o dominio
  padrao salvo nas configuracoes.
- Maquina local sem dominio: digite o usuario administrativo local (exemplo: Administrador).

Configuracao de dominio ou servidor LDAP:
Para operar em clientes, filiais ou dominios diferentes:
1. Clique no icone de engrenagem [⚙] no canto superior direito do login.
2. Informe o novo dominio ou clique em "Detectar Dominio" para preencher com o
   dominio da maquina atual.
3. Se o DNS local nao resolver o controlador de dominio automaticamente, informe
   o endereco no campo Host LDAP alternativo.
4. Clique em Salvar. As configuracoes passam a valer de imediato e ficam salvas
   em %LocalAppData%\PrinterInstall\settings.json.

As credenciais digitadas permanecem apenas na memoria durante a execucao e nao sao
gravadas em disco.


================================================================================
3. INSTALACAO DE IMPRESSORAS EM LOTE (DEPLOY)
================================================================================

A tela principal reune a selecao de computadores alvos, a configuracao das filas
e o painel de execucao.

--- 3.1 Adicao de computadores alvos ---
No painel esquerdo, inclua as estacoes que receberao as impressoras:
- Na propria maquina: clique no botao "Adicionar Este PC".
- Em estacoes remotas: digite o nome de rede (exemplo: NOTE-001234) ou o endereco IP
  (exemplo: 192.168.10.120) e pressione Enter ou clique em "+".
- Multiplas estacoes: cole uma lista de nomes ou enderecos IP diretamente no campo.
  O sistema separa as linhas e adiciona cada registro.

--- 3.2 Configuracao das filas de impressao ---
No painel central, defina as impressoras a instalar:
1. Marca do equipamento:
   - Epson: impressoras jato de tinta e multifuncionais (driver universal Epson).
   - Lexmark: impressoras laser para receitas e prontuarios (driver universal Lexmark).
   - Brother: impressoras laser de posto e administrativo (HL-L5212DW).
   - Gainscha: impressoras termicas de etiquetas (GA-2408T via SSDAL).
2. Endereco IP da impressora: digite o IP fixo de rede (exemplo: 192.168.10.50).
3. Nome da fila: escolha um nome padronizado para identificacao no Windows.
   Exemplos:
   - POSTO-ENF-LASER-01
   - RECEPCAO-EPSON-01
   - TRIAGEM-ETIQ-PULSEIRA
   - LAB-ETIQ-TUBOS
   Caso selecione uma marca de folha comum e utilize termos como ETIQ ou PULSEIRA
   no nome da fila, o sistema apresenta um aviso na tela para confirmar se a marca
   esta correta.
4. Presets para impressoras Gainscha:
   Ao selecionar a marca Gainscha, selecione o tamanho do rolo instalado:
   - Paciente: 89 mm x 36 mm (identificacao de leitos e prontuarios).
   - Matrix: 50 mm x 30 mm (tubos de coleta e frascos de laboratorio).
   - Pulseira: 25 mm x 270 mm (pulseiras de identificacao de pacientes).
   - Lote: 45 mm x 13 mm (medicamentos e farmacia).

--- 3.3 Inicio e acompanhamento da instalacao ---
1. Apos preencher computadores e impressoras, clique no botao "Iniciar Instalacao".
2. O sistema processa os computadores em paralelo e atualiza o estado de cada maquina:
   - Pendente: aguardando inicio da chamada.
   - Testando conexao com impressora: envia requisicao a porta raw 9100 da impressora
     antes de aplicar alteracoes na estacao. Se a impressora estiver desligada ou
     inacessivel, o processo daquela fila e interrompido para evitar filas orfas no Windows.
   - Instalando driver: registro do pacote de driver no repositorio de drivers do Windows.
   - Criando porta e fila: criacao da porta TCP/IP e da fila de impressao.
   - Concluido: impressora instalada e pronta para impressao.
   - Falha: detalhe do erro registrado no log. Falhas em uma maquina nao interrompem
     o processamento das demais.
3. Ao finalizar, clique em "Exportar Logs" para salvar um arquivo de texto com o
   relatorio de instalacao.

--- 3.4 Reversao automatica (Rollback) ---
O orquestrador registra cada recurso criado no diario de deploy da maquina. Se ocorrer
queda de rede, falha em comando intermediario ou cancelamento pelo usuario, o sistema
executa o rollback naquela estacao, removendo portas e filas recem-criadas para evitar
configuracoes incompletas.


================================================================================
4. ASSISTENTE DE CONTROLE DE IMPRESSORAS
================================================================================

O assistente atende trocas de parque, remocao de impressoras desativadas, renomeacao
de filas e recuperacao de filas travadas.

  +-------------------------------------------------------------------------+
  |                  ASSISTENTE DE CONTROLE DE IMPRESSORAS                  |
  +-------------------------------------------------------------------------+
  | [X] 113-DESK004567 | IMP_ANTIGA_HP   (Porta: 192.168.1.99) -> [Remover] |
  | [ ] NOTE-001234    | EPSON-REC-01    (Porta: 192.168.1.50) -> [Manter]  |
  |                                                                         |
  | Acoes: [ Excluir Selecionadas ]   [ Renomear Fila ]   [ Reiniciar Spooler]|
  +-------------------------------------------------------------------------+

--- 4.1 Consulta de impressoras instaladas e deteccao de conexao ---
1. Informe as maquinas que deseja consultar (ou use "Adicionar Este PC") e clique em Avancar.
2. O sistema realiza sondagem rapida via ping ICMP e verificacao de portas administrativas (RPC/SMB).
   - Estacao online: exibe a indicacao de ping ativo e carrega a lista de impressoras.
   - Estacao offline ou desligada: a resposta ocorre em cerca de 2 segundos, evitando
     esperas longas de timeout do Windows. A interface permanece desbloqueada, permitindo
     avancar para as proximas maquinas ou usar "Testar Novamente" apos ligar o computador.
3. O botao Avancar permanece acessivel mesmo sem realizar modificacoes, permitindo
   apenas auditar as filas de cada estacao.

--- 4.2 Remocao de filas e limpeza de portas ---
1. Marque as impressoras que serao desativadas.
2. Clique em "Remover Impressoras Selecionadas".
3. O sistema exclui as filas e apaga as portas TCP/IP que ficarem sem associacao.

--- 4.3 Renomeacao de filas ---
1. Selecione a impressora na listagem.
2. Digite o novo nome no campo de texto.
3. Clique em "Renomear". A alteracao e aplicada diretamente no Windows da estacao,
   sem reinstalacao de driver.

--- 4.4 Reinicio remoto do spooler e purga de documentos presos ---
Quando uma estacao apresenta documentos travados com status "Excluindo..." ou que
bloqueiam novos envios:
1. No passo 1 do assistente, selecione a maquina desejada.
2. Clique no botao "Reiniciar Spooler".
3. Confirme a operacao na janela de aviso. O procedimento executa:
   - Parada do servico de Spooler do Windows (Spooler).
   - Exclusao dos arquivos temporarios em C:\Windows\System32\spool\PRINTERS\*.*.
   - Inicializacao do servico e confirmacao de status ativo.
4. A lista de impressoras da estacao e atualizada logo apos a conclusao.

5. FERRAMENTA DE TESTE DE REDE DIRETO
================================================================================

Permite testar a comunicacao com a impressora antes de iniciar o deploy nas estacoes:
1. Acesse o menu "Teste de Rede Direto".
2. Digite o endereco IP da impressora (exemplo: 192.168.10.45).
3. Selecione a marca do equipamento.
4. Para Gainscha, escolha o preset correspondente ao rolo instalado.
5. Clique em "Testar Conexao" para verificar se a porta raw 9100 responde.
6. Clique em "Imprimir Pagina de Teste" para enviar o comando de teste diretamente
   pelo socket TCP:
   - Epson, Brother e Lexmark: emite folha de teste via PCL5 com data, hora e IP.
   - Gainscha: emite etiqueta calibrada nas medidas do preset via TSPL.

7. RESOLUCAO DE PROBLEMAS FREQUENTES (FAQ)
================================================================================

[?] 1. Erro: "Nao foi possivel conectar ao computador alvo (WMI / CIM / RPC)"
    Causas frequentes: estacao desligada, cabo de rede desconectado, bloqueio de
    firewall local ou usuario sem permissao administrativa na maquina.
    Procedimento: faca um teste de ping para o computador (ping NOTE-001234 ou
    ping 192.168.10.120). Certifique-se de que a conta utilizada tem perfil de
    suporte ou administrador no dominio.

[?] 2. Erro: "A impressora nao respondeu na porta 9100"
    Causas frequentes: impressora desligada, endereco IP incorreto, cabo de rede
    desconectado ou isolamento em VLAN diferente.
    Procedimento: valide o IP na ferramenta de Teste de Rede Direto e verifique
    se o led de rede no conector traseiro da impressora esta aceso.

[?] 3. Impressora Gainscha imprime uma etiqueta e salta etiquetas em branco
    Causa: o preset escolhido no PrinterInstall tem altura superior a etiqueta
    colocada fisicamente na impressora.
    Procedimento: acesse o Assistente de Controle de Impressoras, remova a fila
    configurada incorretamente e instale novamente selecionando o preset correto
    de acordo com a tabela de medidas.

[?] 4. Como interromper uma instalacao em andamento?
    Procedimento: clique no botao "Cancelar". O sistema finaliza a etapa atual
    e aciona a reversao automatica (Rollback) nas estacoes com instalacao incompleta.

[?] 5. Onde ficam gravados os relatorios e arquivos de log?
    Os registros operacionais sao salvos na pasta:
    %LocalAppData%\PrinterInstall\Logs
    Tambem e possivel salvar uma copia em outro diretorio utilizando o botao
    "Exportar Logs".

8. PREFERENCIAS DE DOMINIO E REDE
================================================================================

O PrinterInstall permite personalizar o dominio e o servidor LDAP para operacao
em diferentes redes:
1. Na tela de login, clique no icone de engrenagem [⚙].
2. Ajuste os campos necessarios:
   - Dominio Padrao: nome do dominio Active Directory (exemplo: hospital.local ou EMPRESA).
   - Botao Detectar Dominio: identifica e preenche o dominio em que a maquina local esta associada.
   - Host LDAP Alternativo: IP ou FQDN de um controlador de dominio especifico, util quando
     a resolucao DNS local nao responde pelo dominio.
3. Clique em Salvar. Os parametros sao gravados em:
   %LocalAppData%\PrinterInstall\settings.json
   Os dados permanecem salvos entre execucoes do aplicativo.

9. PUBLICACAO E GERACAO DE EXECUTAVEL
================================================================================

O projeto conta com fluxo de geracao automatica via GitHub Actions e script
local de publicacao:

Metodo 1: Automacao por tag Git
1. Envie os commits aprovados para a branch principal:
   git add .
   git commit -m "feat: melhorias no sistema"
   git push origin main
2. Crie e envie a tag da versao:
   git tag v2.0.0
   git push origin v2.0.0
3. O fluxo de CI/CD compila a solucao, executa os testes automatizados e gera o
   executavel unico na release do GitHub.

Metodo 2: Compilacao manual via PowerShell
1. No terminal PowerShell, execute o script de publicacao da pasta scripts:
   powershell -ExecutionPolicy Bypass -File .\scripts\Publish-PrinterInstall.ps1 -Configuration Release
2. O executavel unico e gerado no caminho:
   publish\PrinterInstall\Printer Install.exe

Metodo 3: Publicacao via GitHub CLI (gh)
1. Gere o executavel com o script de publicacao.
2. Crie a release no repositorio:
   gh release create v2.0.0 "publish\PrinterInstall\Printer Install.exe" --title "Release v2.0.0" --generate-notes
